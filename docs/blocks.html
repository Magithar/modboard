modboard · how blocks work

v0.5.1 · storage blocks hold the board; display blocks draw it in each Claude session

  TWO KINDS OF BLOCK

        storage block     where the board is kept        one per board     .modboard/config.json
        (an adapter)

        display block     what a Claude session shows    many, in order    the plugin's settings


  MAKE YOUR OWN                      the README's "Make your own block" walks through each

        a storage block (an adapter)    a module: createStore → five methods          test: storeContract
        a display block, no code        a shell command in the blocks setting         its first line, every 30 s
        a display block in code         a file in hooks/blocks/, in index.ts          in your copy of the mod

  STORAGE BLOCKS:  WHAT THE ENGINE ASKS OF ONE

        now()                 the store's clock          leases are timed by it, so every machine agrees
        snapshot()            every task and agent       each with the version it was read at
        commit(writes)        all of them, or none       only if every version still matches
        events(since)         the ledger after a seq     what happened, in order
        verify()              does it add up?            what board doctor reports

        every change runs the same loop:

            snapshot() ──▶ decide (the rules) ──▶ commit(writes)
                ▲                                       │
                │                                       ├── ok ─────────▶ done
                └─── a version moved: retry (max 50) ───┘

        check a block:   storeContract('my block', () => createStore(config, { dir }))
                         from modboard/lib/contract.mjs


  STORAGE BLOCKS:  WHY THE VERSIONS   (agents A and B claim T-001 at the same moment)

                 agent A                       the adapter                        agent B

        1   snapshot(): T-001 at v3    ◀──     T-001   v3      ──▶    snapshot(): T-001 at v3
        2   commit: claim T-001,       ──▶     v3 matches:
            only if still v3                   write it, now v4
        3                                      v4, not v3:     ◀──    commit: claim T-001,
                                               conflict        ──▶    only if still v3
        4                                                             the engine reads again:
                                                                      A holds T-001
        5                                                             refused: already claimed
                                                                      (exit 6, in the ledger)

        the engine makes every decision; the adapter only keeps the versions honest
        checking the version and writing must be one step: a transaction, a conditional write, a lock
        as two steps, both claims could pass the check, and two agents would hold one task

  DISPLAY BLOCKS:  WHAT ONE IS

        { name,                                   each draws from one context:
          band?(ctx) ──▶ its forms, widest first      tasks · agents · who you are
                         [ { tree, width }, ... ]     usage · context · model · effort · the time
                         or null: nothing to say      your command blocks' output · the task file
          pane?(ctx) ──▶ one part of the pane         the width · which groups are open
                         or null                      act: nextModel · nextEffort · compact
          brief?(ctx) ─▶ a bar's figures, for the     toggleTaskfile · nextTier · toggleGroup
                         folded Limits heading }      showGroup · openBoard


  DISPLAY BLOCKS:  HOW THE BAND FITS ONE LINE

        room = the line's width, less 4 for Claude Code's own [-] control

        1  every block offers its widest form
        2  too long?  narrow the others, last block first
        3  still too long?  drop blocks from the end
        4  still too long?  narrow the first block (the summary); its alert outlasts its counts
        5  never wraps; with nothing to say, the line disappears
